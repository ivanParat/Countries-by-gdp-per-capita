# Countries by gdp per capita
Explore current and past gdp per capita data by country through various visualizations, such as maps, line graphs and tables. <br>
Try it out: https://countries-by-gdp-per-capita-jt4cyy.streamlit.app/ <br><br>
**Data source:** World Bank — World Development Indicators (GDP per capita, nominal and PPP).
